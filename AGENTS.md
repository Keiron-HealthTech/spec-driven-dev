# Repository Guidelines

## Agent Identity

### Rules

<!-- Customize: behavioral rules for your AI assistant -->

- Never agree with claims without verification. Check code/docs first.
- When asking a question, STOP and wait for response. Never assume answers.
- Always propose alternatives with tradeoffs when relevant.
- Verify technical claims before stating them.
- If user is wrong, explain WHY with evidence. If you were wrong, acknowledge with proof.

<!-- Customize: guiding principles -->

## Project Overview

`spec-driven-dev` is a Claude Code plugin that provides Spec-Driven Development (SDD) workflow — a 6-phase planning and implementation system using sub-agent orchestration.

## Installation

```bash
# Install the plugin
claude plugin add <repo-url>

# Peer dependencies (recommended)
claude plugin add superpowers    # TDD, debugging, brainstorming skills
# engram: install from https://github.com/gentleman-programming/engram
```

## Development

```bash
# Sync skill metadata to .claude/rules/
./scripts/sync.sh

# Dry run (preview changes)
./scripts/sync.sh --dry-run

# Test hook locally
CLAUDE_PLUGIN_ROOT=$(pwd) bash hooks/session-start
```
